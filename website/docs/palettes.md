# Palettes

This page lists every curated MudShell palette in alphabetical order.

## Maintenance note

When you add a new palette, add:

- the palette name,
- a light preview image,
- a dark preview image,
- a short note if needed.

Keep this page sorted alphabetically so all palettes stay easy to compare in one view.

## Future automation

Later, add a small script that generates the light and dark PNG previews from each palette definition and writes them to `website/static/img/palettes/`.
Reuse the same naming scheme as this page so every new palette can be documented and previewed at the same time.
